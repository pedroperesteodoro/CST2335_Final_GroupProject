CST2335 — Main screen only (4 buttons): what changed
=====================================================
Date: aligned with SQLite.txt and Responsive Layouts.txt course notes.

Goal
----
Reduce the previous lab (shopping list with TextFields, ListView, long-press
delete dialog) to a single launcher: one main screen with four buttons that
open a simple placeholder page per topic, ready for teammates to replace with
real Pet Owner / Pet / Vaccine / Veterinarian features.

Files modified
--------------

1) lib/main.dart
   - REMOVED: Shopping list state (_HomePageState), item/quantity controllers,
     in-memory list, ListView.builder, long-press AlertDialog delete flow,
     and flutter/services import (FilteringTextInputFormatter).
   - ADDED: MaterialApp theme (seed color, Material 3).
   - RENAMED conceptually: HomePage -> MainMenuPage (StatelessWidget; no list
     state on the menu).
   - ADDED: Four FilledButtons — Pet Owners, Pets, Vaccines, Veterinarians.
     Each calls Navigator.push to ModuleLandingPage with a title string.
   - ADDED: ModuleLandingPage — minimal Scaffold with AppBar + centered text
     so each button "launches a page" as required by the final project spec.
   - ADDED: Dartdoc (///) comments on MyApp, MainMenuPage, ModuleLandingPage,
     and the title field, per project Dartdoc requirement.
   - RESPONSIVE LAYOUTS.txt: Main menu uses SafeArea, Center, ConstrainedBox
     (maxWidth 400), ListView + padding so buttons stay readable on phones and
     wide screens. The course master–detail pattern (Row with Expanded, width
     > height && width > 720) is documented in code comments as applying to
     each module’s list/detail screen later — not to this four-button menu.

2) pubspec.yaml
   - REMOVED: encrypted_shared_preferences, shared_preferences (not used by
     the launcher; add back per module when implementing EncryptedSharedPreferences).
   - REMOVED: dev_dependency url_launcher (unused in lib/).
   - REMOVED: assets: images/light-bulb.jpg, question-mark.jpg, stop-sign.jpg
     — those paths had no matching files in the project and would break builds.
   - UPDATED: description string to reflect the group project.
   - NOTE: When you add Floor/SQLite per SQLite.txt, add floor, floor_generator,
     build_runner under dependencies / dev_dependencies and run build_runner.

3) test/widget_test.dart
   - REPLACED: Old counter smoke test (0/1, Icons.add) which did not match any
     code in main.dart.
   - NEW: Pumps MyApp and asserts AppBar title "Veterinary Clinic" and the four
     button labels are present.

Files not changed
-----------------
- analysis_options.yaml (unchanged)

How this maps to course notes
-----------------------------
- SQLite.txt: No database on the main menu yet. Each teammate adds Floor
  entities, DAO, database class, and initState loading per that document when
  implementing their ListView + persistence.
- Responsive Layouts.txt: reactiveLayout / master–detail belongs on each
  feature page (list left, details right on tablet/desktop); phone navigates
  full-screen. The main screen stays a simple button column as above.

Next steps (for your group, not done in this edit)
--------------------------------------------------

- Re-add encrypted_shared_preferences, shared_preferences, floor, etc. in
  pubspec.yaml as each module needs them.
- Generate Dartdoc output into a Dartdoc folder when the course requires it.
