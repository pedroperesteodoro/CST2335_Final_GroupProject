PHASE 3 — Floor SQLite database (SQLite.txt)
==============================================================================

Goal
----
Add a single SQLite database shared by all modules, using Floor (see course
SQLite.txt: entities, @dao, @Database, build_runner).

Dependencies (pubspec.yaml)
----------------------------
- dependencies: floor, sqflite (Floor tutorial style; sqflite is explicit for clarity).
- dev_dependencies: floor_generator, build_runner.

New / generated files
---------------------
- lib/data/entities/pet_owner.dart      — PetOwner table (pet_owners).
- lib/data/entities/pet.dart          — Pet table (pets).
- lib/data/entities/vaccine.dart       — Vaccine table (vaccines).
- lib/data/entities/veterinarian.dart  — Veterinarian table (veterinarians).
- lib/data/daos/*.dart                 — One DAO per entity (findAll, insert,
                                         update, delete).
- lib/data/app_database.dart           — @Database(version: 1, entities: [...]).
- lib/data/app_database.g.dart         — GENERATED; do not edit by hand.
- lib/data/database_holder.dart        — Opens vet_clinic.db once via
                                         $FloorAppDatabase.databaseBuilder(...).

Regenerate after changing entities or DAOs:
    dart run build_runner build --delete-conflicting-outputs

PHASE 4 — Base screens for each module + responsive details (Responsive Layouts.txt)

New files
---------

  (no placeholder ModuleLandingPage).
